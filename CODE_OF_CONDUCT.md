# Code of Conduct

We want this project to be a friendly place for everyone who wants to help, whatever their experience, background or identity.

## What we expect

- Be respectful and patient. Assume good intentions.
- Give feedback on the work, not the person, and say what you would change.
- Accept feedback gracefully; reviews exist to make the code better.
- Keep discussions on topic and in English so everyone can follow.

## What is not acceptable

- Harassment, insults, discrimination or personal attacks.
- Publishing other people's private information.
- Spam, trolling or deliberately derailing discussions.

## Enforcement

Maintainers may edit or remove comments, issues and pull requests that break these rules, and may block repeat offenders. To report a problem, contact the maintainers (for example by opening a private security advisory or contacting the repository owner on GitHub).

This is a short, informal code; the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) is a good longer reference for the same spirit.
